# Flincth website

- Write all code, comments, commit messages and documentation in English.
- Exception: translated site content. Translation files (`_data/i18n/<lang>.yml`) and translated pages (`<lang>/*.html`) contain text in their own language; their comments and keys stay in English.
- The site is built by GitHub Pages with Jekyll; see README.md for the structure and how to add a language.
- App icons and logos follow the `flincth-design` skill in `safakveziran/Flincth` (`.claude/skills/flincth-design/references/app-icons.md`): web icons are full-bleed, fill 100% of their box, and every copy (`assets/*-icon-*`, OG images) is replaced together.
