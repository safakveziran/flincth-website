Stuck on something? Let’s sort it out.

Most questions turn out to be one of the few below. Pick your app; if your question isn’t here, write to us. A real person reads it.

Workspace Manager (Mac) · Split View (browser) · Speed Reader (iPhone and iPad)

Flincth Workspace Manager

Requirements

Flincth Workspace Manager needs a Mac with macOS 14 or later. Window placement additionally needs the “Flincth Apply” shortcut, which you install yourself in Apple Shortcuts. The app walks you through it the first time you need it.

Windows aren’t moving

Almost always one of three things:

  • The Flincth Apply shortcut isn’t installed yet. Open the app’s setup instructions and install it in Apple Shortcuts.
  • The window is full screen. Flincth works with ordinary, non-full-screen windows. It cannot move a window into or out of macOS full screen.
  • The window is on another desktop. Placement applies to the desktop you are currently on. Flincth does not move windows between Mission Control desktops.

Setups and clipboard

Each setup keeps its own apps, its own layout, and its own text clipboard history. Editing one setup never changes another. The clipboard history holds text and stays on your Mac.

Keyboard shortcuts

The shortcuts shown on the website are examples. You assign your own inside the app, and you can always switch setups from the menu bar instead.

The Workspace Manager guides walk through installing the shortcut, building a setup and using clipboard history step by step.

Flincth Split View

Split View works in Chrome, Microsoft Edge and Firefox 140 or later. If a site stays blank in a pane, it refuses to be shown inside another page; open that pane as a window instead. Website access and keyboard shortcuts work a little differently in each browser, so the guides are written per browser: Chrome, Firefox and Edge.

Flincth Speed Reader

Speed Reader is coming soon to iPhone and iPad. Until then, the Speed Reader page covers what it reads, how Pro works and how to be told when it launches.

Still stuck?

Email support@flincth.com. Telling us which app, your macOS, iOS or browser version, what you tried and what happened instead gets you a useful answer far faster than “it doesn’t work”.
