When a file can't be opened, Flincth Speed Reader says why in a message titled *Couldn't open* followed by the file's name. Find the message below.

## “This book is copy-protected (DRM).”

Books bought from Kindle, Apple Books and most other stores are locked with DRM, and only their own apps can open them. Flincth reads DRM-free books only.

DRM-free EPUBs come from many places: public domain libraries such as Project Gutenberg and Standard Ebooks, publishers and authors who sell without DRM, and your own documents. More in [can you speed read Kindle books?](/blog/can-you-speed-read-kindle-books)

## “This PDF has no selectable text (it's probably a scan).”

A scanned PDF is a set of pictures of pages, with no text Flincth can read. If you can't select a word in the PDF in another app, it's a scan.

Run it through a text recognition (OCR) tool that keeps the result as a searchable PDF, then add the new file.

## “Old Word (.doc) files aren't supported.”

Open the file in Word or Pages, save it as **.docx**, and add that.

## “This file is password-protected.”

Remove the password in the app that created the file, then add it again.

## “Flincth can't open this file type.”

Supported files are EPUB, PDF, DOCX, TXT, RTF and Markdown. MOBI, AZW and AZW3 aren't supported; if the book is DRM-free, convert it to EPUB first.

## “This file looks damaged and couldn't be opened.”

The file is incomplete or corrupt. Download or export it again and add the new copy.

## “There's no readable text in this file.”

The file opened but held no text, such as a PDF made only of images. Check the file in another app.

## “This file is larger than 200 MB, which Flincth can't open.”

Split the document into parts, or export a version without large images.

## “Paste text, not a link.”

Flincth doesn't load web pages. Copy the text you want and paste it into [Quick Read](/guides/ios/quick-read-pasted-text), or share the selected text. For a book, download its EPUB or PDF and use **Add File…**.

## “The free plan keeps … documents.”

This isn't an error: the library is full on the free plan. Delete a document you've finished, or get an unlimited library with [Pro](/guides/ios/pro-trial-and-restore-purchases).

Something else? [Contact support](/support#speed-reader) with the message you see. Never send the document itself unless you want to; we don't need it to help.
