A FEW THINGS TO KNOW

Good questions.

What do I need to run Flincth?+

A Mac running macOS 14 or later. Window placement also requires the user-installed Flincth Apply shortcut. The app guides you through installing it in Apple Shortcuts.

Can it move windows between desktops?+

No. Window placement works with open, non-full-screen windows on the current desktop. Flincth does not move windows between Mission Control desktops or into or out of macOS full screen.

Does my clipboard leave my Mac?+

No. Flincth keeps text clipboard history locally, with a separate history for each setup. It has no account, server, or network access.

Does changing one setup affect another?+

No. Each setup keeps its own app membership, layout, and placements. Editing an app’s placement in one setup leaves your other setups unchanged.
