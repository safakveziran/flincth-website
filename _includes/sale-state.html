{%- comment -%} The sale of one product's data file: include.data is the file's name (mac or reader; mac by default), the store_data of its product in _data/products.yml. Sets sale its sale block, or nil sale_on true while the build time is inside the sale's window sale_off_percent the discount, rounded down to a whole percent sale_regular the usual price (price, or pro_price for Speed Reader) sale_store_url the product's store link sale_product the product's entry in _data/products.yml sale_data_key include.data Pages render a deal only when sale_on is true; sale.js then removes every [data-sale-ends] element in the browser once that time passes, so a page built during the sale stops showing it on time. These are page-wide variables: include this again before printing another product's sale. {%- endcomment -%} {%- assign sale_data_key = include.data | default: "mac" -%} {%- assign _sale_src = site.data[sale_data_key] -%} {%- assign sale = _sale_src.sale -%} {%- assign sale_regular = _sale_src.price | default: _sale_src.pro_price -%} {%- assign sale_store_url = _sale_src.store_url -%} {%- assign sale_product = site.data.products | where: "store_data", sale_data_key | first -%} {%- assign sale_on = false -%} {%- assign sale_off_percent = 0 -%} {%- if sale and sale.price -%} {%- assign _sale_now = site.time | date: "%s" | plus: 0 -%} {%- assign _sale_start = sale.starts | date: "%s" | plus: 0 -%} {%- assign _sale_end = sale.ends | date: "%s" | plus: 0 -%} {%- if _sale_now >= _sale_start and _sale_now < _sale_end %}{% assign sale_on = true %}{% endif -%} {%- assign _sale_regular_cents = sale_regular | times: 100 | round -%} {%- assign _sale_cents = sale.price | times: 100 | round -%} {%- assign sale_off_percent = _sale_regular_cents | minus: _sale_cents | times: 100 | divided_by: _sale_regular_cents -%} {%- endif -%}
