{{ gb.name }} can already show two tabs side by side. When two isn't enough (a dashboard, a document, a chat and a calendar all at once), you need a different tool. This guide shows both: {{ gb.name }}'s own {{ gb.native_name }} for two sites, and Flincth Split View for three to eight.

## Two sites: {{ gb.name }}'s {{ gb.native_name }}

{{ gb.native_how }}

Drag the line between the two halves to give one side more room. It is quick, built in, and each side stays an ordinary tab, so sign-ins, extensions and downloads behave exactly as usual.

What it doesn't do: show a third site, or remember the pair once you close it.

## Three or more sites: Flincth Split View

Flincth Split View is a free extension that divides one tab into as many as eight panes, each with its own site, and saves the arrangement as a workspace you can come back to.

1. **Install it.** Follow [How to Install Flincth in {{ gb.name }}]({{ g }}/install-flincth).
2. **Create a workspace.** Click the Flincth icon in the toolbar, then **New workspace**. Give it a name and pick **Three columns**, **Wide left, two right** or **Four grid** as the layout.
3. **Add more panes if you need them.** Use **Split left / right** or **Split top / bottom** in any pane's toolbar, up to eight panes.
4. **Put a site in each pane.** Type an address or click **Choose from open tabs**.
5. **Size them.** Drag the dividers. They catch on halves, thirds and quarters so separate rows line up.

The workspace is saved as you go. Close the tab, and the next time you open Flincth every site is back where you left it. The full walkthrough is in [How to split {{ gb.a_tab }} into your first workspace]({{ g }}/split-a-tab-into-a-workspace).

## Which one to use

| | {{ gb.name }}'s {{ gb.native_name }} | Flincth Split View |
|---|---|---|
| Sites side by side | Two | Up to eight |
| Remembers the arrangement | No | Yes, as named workspaces |
| Switch between arrangements | No | Click or keyboard shortcut |
| Each side is a normal tab | Yes | Sites show inside one tab; a site that refuses can open as a window lined up with its pane |

If you compare two pages now and then, {{ gb.name }}'s own feature is all you need. If you rebuild the same three or four sites every morning, a saved workspace saves that time.

## When a site won't show

Some sites refuse to be shown inside another page, and some need a sign-in that an embedded view can't reach. Flincth can open those as a real window lined up with the pane, or as a card that opens a normal tab. See [When a site won't show in a pane]({{ g }}/when-a-site-wont-show-in-a-pane).
