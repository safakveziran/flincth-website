Present one pane. Keep everything ready.

Available in version 1.1.0. Store updates may reach browsers at different times.

Let your audience follow your focus.

Presentation mode keeps the focused pane clear. Other panes receive a frosted-glass cover with a small favicon and the page title. Switch focus with the numbered controls and press Esc to return to your workspace.

Covered pages stay running and may play audio. The cover is a visual aid, not a way to hide sensitive information securely.

Drop a document beside your sites.

Drag an image, HTML, PDF or text file into a pane, or choose a file from an empty pane. Local copies stay available after restarting in the same browser profile, up to 50 MB per file.

Copied HTML is a static preview. For scripts and nearby resources, use the original file URL or full path and enable the browser’s local-file access.
