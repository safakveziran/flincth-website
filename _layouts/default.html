{%- comment -%} Shared skeleton for every page. The language comes from the page's lang value (_config.yml) and the copy from _data/i18n/.yml. A page with all_languages: true (404) carries every language in its own block and the browser picks one. On the home page (ref: home) menu links point to in-page anchors; elsewhere they point to the anchors on that language's home page.
